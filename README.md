# Puzzle Journey

A Block Blast–style puzzle game: drag colorful polyominoes onto an 8×8 board, clear rows and columns, and use bombs, rockets, and stones.

Clear · Relax · Level Up

## Play

- Drag a piece from **Next Blocks** onto the board
- Fill a full row or column to clear it
- Specials: **arrow** (row/column), **bomb** (3×3), **stone** (takes a hit)
- Boosters: Hammer, Shuffle, Bomb, Freeze
- Sound effects and music can be toggled separately in the top bar or Settings

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL, then play.

## Stack

React, TypeScript, Vite, Tailwind, Zustand
